Remember: main.tsx starts React. App.tsx defines the main UI. Think of main.tsx as the entry point and App.tsx as the first main component.

2. JSX

const title = 'My Fullstack Roadmap'

<h1>{title}</h1>

{ } means: run a JavaScript/TypeScript expression inside JSX. Example: {title} displays the current value stored in title.

3. Components

function TopicCard() {
  return <section>...</section>
}

A component is a reusable piece of UI. Instead of repeating the same markup, we build it once and reuse it with different data.

4. Props

type TopicCardProps = {
  title: string
  description: string
}

function TopicCard({ title, description }: TopicCardProps) {
  return (
    <section>
      <h2>{title}</h2>
      <p>{description}</p>
    </section>
  )
}
<TopicCard
  title="React"
  description="Learning React fundamentals."
/>

Core idea: Parent sends props → child receives props → child renders UI. Props let the same component display different content without duplicating its structure.

5. Arrays + Objects

const topics = [
  {
    title: 'React',
    description: 'Learning React fundamentals.',
    status: 'In Progress',
  },
]

Array = list/collection. Object = grouped related properties. Here, topics is the list and each topic is one object inside that list.

topic.title = property access / dot notation.

6. .map() ⭐

{topics.map((topic) => (
  <TopicCard
    key={topic.title}
    title={topic.title}
    description={topic.description}
    status={topic.status}
  />
))}

.map() goes through each array item and returns a transformed result for each item. In React, this is commonly how an array of data becomes a list of UI components.

Read it:
“Go through the topics array and, for each topic, return a TopicCard.”
Taglish: “Isa-isahin yung topics array, then gumawa ng TopicCard for every topic.”

7. Arrow Function

(topic) => (
  <TopicCard />
)

=> = arrow function. Receive a value → return something. In .map(), the current array item is received, then we return the UI for that item.

8. key

key={topic.title}

key uniquely identifies list items so React can track changes. A stable database ID is usually better than a title when one is available.

9. TypeScript Union Type

status: 'In Progress' | 'Next'

| means OR. Only those values are allowed. This gives better type safety than accepting any possible string.

10. Essential Vocabulary

  • Render — display/produce UI.
  • Import — bring code from another file.
  • Export — make code available to other files.
  • Reusable — can be used many times.
  • Dynamic — value comes from data, not hardcoded text.
  • Type-safe — TypeScript checks allowed value types.
  • Iterate — go through items one by one.

Small Concepts Worth Remembering

  • Function — reusable block of code that can receive input and return output.
  • Variable — named place/reference for a value, such as title.
  • Parameter — input name received by a function, such as topic.
  • Method — function attached to a value/object, such as array .map().
  • DOM — browser representation of the HTML document; React renders UI into it.
  • Dependency — package the app needs to run, such as React.
  • Dev dependency — package mainly needed while developing/building, such as Vite or TypeScript.

18. React + Full-Stack Preview — Future Study

These are important future topics. Hindi pa ibig sabihin na learned na natin. Use this section para maging familiar ka sa words and ideas before we reach them in the lessons.

React: State

State is data a component can remember and change while the app is running. Props come from a parent; state is managed by the component.

const [count, setCount] = useState(0);

Read: “Create a state value called count, starting at 0, and use setCount to change it.”

React: Events

Events let the UI respond to user actions such as clicks, typing, and form submission.

<button onClick={() => setCount(count + 1)}>
  Add
</button>

React: Conditional Rendering

Show different UI depending on a condition.

{isLoggedIn ? <Dashboard /> : <Login />}

condition ? A : B means: if true use A, otherwise use B.

React: useEffect

useEffect is commonly used when a component needs to synchronize with something outside React, such as fetching data or working with browser APIs.

useEffect(() => {
  // side effect
}, []);

Frontend → API → Backend → Database

React UI
   ↓ HTTP request
REST API / Backend
   ↓ query
Database
   ↓ result
Backend
   ↓ JSON response
React UI

This is the basic full-stack flow. The frontend displays and collects data; the backend handles application rules; the database stores persistent data.

API + HTTP Basics

  • API — a defined way for software systems to communicate.
  • HTTP — protocol commonly used for browser/client and server communication.
  • GET — retrieve data.
  • POST — create/send new data.
  • PUT/PATCH — update data.
  • DELETE — remove data.
  • JSON — common text format used to exchange structured data.

Database Basics

A relational database stores information in tables. A table contains rows (records) and columns (fields).

users
id | name   | email
1  | Nelson | ...

Primary key uniquely identifies a row. A foreign key connects related records between tables.

CRUD

CRUD = Create, Read, Update, Delete — four basic operations you will see across frontend forms, APIs, and databases.

Authentication vs Authorization

Authentication: “Who are you?” Example: logging in.
Authorization: “What are you allowed to do?” Example: only an admin may delete a user.
